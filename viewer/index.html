Plan Extraction Eval

Classical CV baseline for room areas on public sample floor plans. Results are measured against hand-checked values; failures are shown on purpose.

What the columns mean
Measured w x d — the room's size from the pixels
The width and depth of the region this tool traced. Set beside the printed size so the two can be compared directly: on the sample sheet the Dining Room measures 14'9" x 24'6" against a printed 14'10" x 24'4", which is under one percent on both sides.
Computed sq ft — what this tool worked out
It finds the room on the drawing, traces the walls around it, counts the pixels inside, and converts to square feet using the drawing's scale. Nobody typed this number in. It is only as good as that scale: if the scale is wrong by 5%, every area here is wrong by about 10%, and nothing in the picture would show it.
Printed size — what the architect wrote on the drawing
The independent check. The tool reads the dimensions off the sheet and works out what the room's width and depth should be. This is the only number on the drawing that did not come from this tool, so it is the only thing that can prove the computed area right. A dash means nothing on the drawing could be tied to this room, which is why the row still needs a human.
Gap vs printed % — how much of the room is floor
How far the computed area sits from the printed width times depth. A room is not a rectangle: closets, chimneys and stairs are cut out of it, so this is usually a real difference and not a mistake. It is reported, not judged.
What decides whether a room agrees
Its measured width against the printed width, and its measured depth against the printed depth, each within 8%. Like against like. Comparing the floor area with width times depth would fail every room that has a closet in it.
Read so far — the half of the answer already found
A room needs a width and a depth before it has a size. Often only one has been found: the architect wrote it once, on a run this tool could read, and the other side is written somewhere it could not. This column shows what has been read, so a row that looks empty under Printed size is not mistaken for a row where nothing was found at all.
True sq ft and Error % — not implemented yet
These are for measuring the tool against areas a person measured by hand and typed into truth.csv. No such file has been made for these drawings, so both columns are empty. They are the difference between "the drawing agrees with itself" and "we checked it against reality", and only the second tells you how accurate this tool actually is.
